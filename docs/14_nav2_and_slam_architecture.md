# 第 14 章：自主导航全栈（Nav2）与 SLAM 建图定位底层架构

在移动机器人（AGV/AMR）、清洁机器人与无人巡检车领域，让机器人“从 A 点自主安全移动到 B 点”是最高频的核心需求。
初学者常以为导航只是写一个 $A^*$ 寻路算法，但在物理真实世界中：
- 机器人具有严格的**动力学与运动学约束**（如两轮差速底盘无法横向平移，具有最大加速度与转弯角速度限制）；
- 环境充满**动态未知障碍物**（如穿行的行人、堆叠的临时货物箱）；
- 轮式里程计存在持续的**积分累积漂移**。

ROS 2 官方标准导航系统 **Nav2（Navigation 2）** 重新定义了移动机器人的自主导航体系。
本章将从 Linux 系统级内存布局、多层代价地图（Costmap2D）、局部控制器算法与 SLAM 粒子滤波定位全方位解构 Nav2。

---

## 14.1 Nav2 工业级导航核心架构与状态闭环

Nav2 摒弃了 ROS 1 navigation 的单体式单进程架构，全面采用**模块化微服务 + 生命周期管理（Lifecycle）+ 行为树编排**设计：

```
+-----------------------------------------------------------+
|               用户端 / 业务系统 / Web 调度集群             |
+-----------------------------------------------------------+
                             | 下发目标 (NavigateToPose Action)
                             v
+-----------------------------------------------------------+
|            行为树导航调度器 (bt_navigator)                |
|  - 实时评估导航状态、重试策略、动态避障与异常恢复 (Recovery)|
+-----------------------------------------------------------+
         |                                          |
         v 调用全局规划                             v 调用局部控制
+---------------------+                    +---------------------+
| 全局规划服务器      |                    | 局部轨迹控制服务器  |
| (planner_server)    |                    | (controller_server) |
| - NavFn (Dijkstra)  |                    | - DWB (动态窗口法)  |
| - Smac Planner (A*) |                    | - MPPI (GPU 模型预测)|
+---------------------+                    +---------------------+
         |                                          |
         +--------------------+---------------------+
                              | 查询障碍物分布
                              v
+-----------------------------------------------------------+
|               2D 空间代价地图 (Costmap2D)                  |
|  [静态地图层]  +  [动态激光障碍物层]  +  [指数膨胀安全层]  |
+-----------------------------------------------------------+
                             |
                             v 输出平滑底层控制速度
+-----------------------------------------------------------+
|          /cmd_vel (geometry_msgs/msg/Twist)               |
|            底盘电机驱动 / ros2_control                    |
+-----------------------------------------------------------+
```

## 14.2 Costmap 2D 内存排布与多层栅格融合机制

在 Linux 内存中，Costmap 2D 并没有使用复杂的网格树，而是采用极其高效的**一维连续内存字节数组（`uint8_t*`）**存储尺寸为 $Width \times Height$ 的栅格：

```cpp
// 坐标 (x, y) 在连续内存中的索引计算公式
size_t index = y * map_width_in_cells + x;
uint8_t cost_value = costmap_buffer[index];
```

### 1. 代价等级语义规约（Cost Semantic Values）
| 栅格代价值 | 常量定义 | 物理意义与导航决策 |
| :--- | :--- | :--- |
| **0** | `FREE_SPACE` | 绝对安全的开阔无障碍区域，机器人可全速通行。 |
| **1 ~ 252** | `INSCRIBED INFLATED` | 膨胀安全衰减区，代价值随着与障碍物距离接近呈指数上升。 |
| **253** | `INSCRIBED_OBSTACLE` | 障碍物边界已侵入机器人**内切圆半径（Inscribed Radius）**，发生碰撞。 |
| **254** | `LETHAL_OBSTACLE` | 物理实体致死障碍物（如激光雷达击中的物理墙壁或立柱）。 |
| **255** | `NO_INFORMATION` | 激光未探测到的盲区或未建图未知区域。 |

### 2. 多层代价地图融合流水线（Layered Costmap）
1. **静态层（Static Layer）**：由 `map_server` 加载已建好的 2D 占据栅格地图（PGM 图片），提供建筑永久墙体结构。
2. **障碍物层（Obstacle Layer）**：
   - 订阅实时激光雷达点云，利用 **Bresenham 画线光线投射算法（Raytracing）** 进行光束穿透清除（Clearing）与端点障碍物标记（Marking）。
3. **膨胀层（Inflation Layer）**：
   - 根据机器人的物理外形轮廓（Footprint），按照以下指数衰减数学公式向四周广播危险代价：
     $$ \text{cost}(d) = 253 \cdot \exp\left( -k \cdot (d - r_{\text{inscribed}}) \right) $$
   - 使得全局规划器在路径搜索时，自然倾向于选择“远离墙角的大路”行走，避免底盘刮擦。

## 14.3 全局规划（Global Planners）vs 局部控制（Local Controllers）

### 1. 全局路径规划器（Global Planner）
负责在全局静态代价地图上搜索一条宏观无碰撞折线：
- **NavFn（Dijkstra）**：波前扩展算法，保证找到全局最短路径，但路径贴近障碍物边界。
- **Smac Planner（2D A* / Hybrid A*）**：
  针对具有阿克曼转向限制（如类似汽车底盘，无法原地自转）的车辆，Smac Hybrid A* 在状态转移中嵌入车辆最小转弯半径与曲率限制（Dubins / Reeds-Shepp 模型），规划出平滑、可由转向舵轮真实跟踪的运动几何曲线。

### 2. 局部轨迹追踪控制器（Local Controller）
负责在每秒 20 次（20Hz）的高频控制回路中，结合车速惯性动态躲避突发动态障碍物：
- **DWB（Dynamic Window Approach）**：
  在机器人当前线速度与角速度的可达加速度窗口内采样几百条短期预测轨迹候选（Rollouts），根据“距离路径接近度”、“避障余量”、“朝向终点程度”进行打分选优。
- **MPPI（Model Predictive Path Integral）**：
  现代极速模型预测控制器，将数千条随机扰动轨迹**直接卸载到 GPU 显卡（CUDA）并发计算**，能够处理高度非线性、易打滑的高速全地形复杂控制。

## 14.4 激光 SLAM 建图与 AMCL 蒙特卡洛粒子滤波定位

### 1. 激光 SLAM（Slam Toolbox / Cartographer）
在未知环境中建图时，核心包含两大技术模块：
1. **前端扫描匹配（Scan Matching）**：
   - 基于优化方法（Ceres Solver）或相关扫描匹配（CSM），将当前帧的点云轮廓与已有子图（Submap）做对齐，推算出机器人位姿跃迁。
2. **后端图优化与回环检测（Loop Closure）**：
   - 机器人在仓库内绕行一圈回到起点时，识别出历史同一位置。
   - 后端位姿图优化器（Pose Graph Optimizer）将累积了几十米的轮式漂移误差一次性在全局拓扑图上进行**最小二乘松弛平差**，瞬间将弯曲扭曲的地图校准拉直。

### 2. AMCL 自适应蒙特卡洛定位数学原理
在已知静态地图中，利用粒子滤波（Particle Filter）解决机器人的全局重定位问题：

$$ p(x_t \mid z_{1:t}, u_{1:t}) \propto p(z_t \mid x_t) \int p(x_t \mid x_{t-1}, u_t) \, p(x_{t-1} \mid z_{1:t-1}) \, dx_{t-1} $$

- **初始化**：在地图范围内撒满数千个具有假设位置与朝向的“假想粒子（Particles）”。
- **运动更新**：底盘轮速计前进，每个粒子根据里程计运动学模型带噪声向前推进。
- **观测打分（Likelihood Field Model）**：激光雷达打出一束光线，计算光线端点与该粒子假设位姿下地图物理障碍物的距离。距离越近，该粒子权重越高！
- **重要性重采样（KLD Resampling）**：淘汰低权重粒子，高权重粒子分裂复制。几秒钟内，粒子群迅速收敛收拢于机器人的真实物理坐标周围。

## 14.5 工业仓储 AGV 现场参数调优避坑秘籍

1. **精准几何轮廓（Footprint）取代圆形半径**：
   - 长方形货架车不能使用单一 `robot_radius: 0.35`，必须显式定义多边形凸包：
     ```yaml
     footprint: "[[0.4, 0.25], [0.4, -0.25], [-0.4, -0.25], [-0.4, 0.25]]"
     ```
2. **清理盲区“鬼影障碍物”（Raytrace Clearing）**：
   - 现场扬尘或反光地面可能在局部 Costmap 留下永久噪点，导致机器人原地自转打转。
   - 务必确保 `clearing: true` 且设置合理的 `raytrace_max_range`。
3. **摆脱震荡陷入困境（Oscillation Prevention）**：
   - 在 DWB 控制器参数中开启 `oscillation_reset_dist: 0.05`，当机器人在极小范围内反复前后拉扯时，主动触发 Recovery 旋转脱困，彻底杜绝死锁。

## 14.6 工业级高级特性：Costmap 过滤器（禁行区与限速区）与多航点巡航

在大型工厂、半导体无尘车间或智慧医院中，机器人不仅要“能走通”，更必须遵循人类制定的交通规则（Traffic Rules）：
- **动态禁行区（Keep-out Zones）**：严禁机器人驶入危险化学品区、高压电房或下行扶梯口；
- **动态限速区（Speed Limits）**：在人流密集交叉路口或转角处强制降速至 0.3 m/s，空旷长直道允许加速至 1.5 m/s；
- **单向通行车道（Preferred Lanes）**：狭窄通道必须靠右行驶，防止对向双车“顶头互锁”。

### 1. Costmap Filters 掩码图层工作原理
Nav2 提供了 **Costmap Filters** 机制，通过将一张独立的语义掩码图片（Mask Image）与物理地图对齐加载：
- **Keep-out Filter**：当掩码图像特定区域像素为 100（黑色）时，Costmap 会在对应内存栅格上直接注入 `LETHAL_OBSTACLE (254)`，全局与局部规划器将其视作坚不可摧的“虚拟墙壁”，完全杜绝误入。
- **Speed Limit Filter**：像素灰度值直接线性映射为最大允许线速度百分比（例如像素值 40 对应限速 40%）。当机器人底盘几何中心进入该像素区域时，Controller Server 自动对电机指令进行硬性削峰限幅。

### 2. 多航点流水线巡航（Waypoint Follower）
在大型厂区安防巡更中，任务通常是按顺序走完 20 个巡检点。
Nav2 的 `waypoint_follower` 引擎支持：
- 依次排队分发导航目标点；
- 在每个航点到达后挂载插件式**航点任务执行器（Waypoint Task Executor）**（例如：在点位 1 执行原地旋转 360 度红外热成像测温，在点位 2 等待升降机门打开确认，在点位 3 触发条形码扫描）。

## 14.7 本章总结

- Nav2 将复杂的移动导航解构为 **全局规划（找路）**、**局部控制（避障）** 与 **代价地图（环境抽象）** 的分工协作。
- 代价地图底层为极简的连续内存一维数组，通过 **Bresenham 光线投射与指数膨胀模型** 实现高效感知更新。
- 掌握 **SLAM 扫描匹配图优化** 与 **AMCL 粒子滤波**，使机器人能够在任意复杂仓储与室内环境中实现毫米级自标定定位。
- 结合 **Costmap Filters 禁行限速** 与 **Waypoint Follower 航点任务**，使自主移动机器人真正具备适应现代工业严苛安全标准的商业化量产落地能力，完成了从底层动力学伺服到宏观业务全自主移动的完整闭环，为现代仓储物流搬运、工厂自动化巡检与智能移动机器人提供了极其可靠的系统工程化支撑。
